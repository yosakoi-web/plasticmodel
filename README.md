# PLAMO STOCK

積みプラと塗料を写真つきで管理する、スマートフォン対応のPWAです。GitHub Pagesだけで公開でき、サーバーや外部データベースは必要ありません。

## 主な機能

1. 未組立と組立済みの管理
2. HG、RG、MG、PG、EG、SD、RE/100、Figure-rise、30MM、30MS、30MFの分類
3. 素組、塗装済み、完成の記録
4. 製作開始日と完成日から製作期間を自動計算
5. 購入日、購入店、購入価格、保管場所、タグ、メモの記録
6. カメラ撮影と写真選択に対応し、最大5枚を保存
7. 縦長写真サムネイルと写真ギャラリー
8. 塗料のメーカー、シリーズ、品番、種類、色見本、在庫本数、開封状況、残量を管理
9. 残量25%以下または在庫0本を要補充として表示
10. 名前、シリーズ、購入店、タグ、メーカー、品番による検索
11. 状態、カテゴリー、塗料種類、残量による絞り込み
12. 写真を含むJSONバックアップの書き出しと復元
13. オフライン起動とホーム画面への追加

## データの保存先

登録データと写真はブラウザのIndexedDBに保存されます。GitHubや外部サーバーへ自動送信されません。ブラウザのデータを削除すると消えるため、データ管理画面から定期的にバックアップしてください。

## GitHub Pagesで公開する

1. このフォルダーの内容をGitHubリポジトリのmainブランチへ追加します。
2. GitHubのSettings、Pagesを開きます。
3. SourceでGitHub Actionsを選びます。
4. mainブランチへの反映後、同梱のワークフローが自動公開します。

## ローカルで確認する

ブラウザの保存機能とPWAを正しく動かすには、ローカルサーバー経由で開きます。

```bash
python3 -m http.server 8080
```

その後、ブラウザで `http://localhost:8080` を開きます。

## 技術構成

外部ライブラリを使わないHTML、CSS、JavaScript構成です。ビルド作業は不要です。

## 操作上の仕様

1. 登録画面を開いた状態で端末やブラウザの戻る操作を行うと、登録画面だけが閉じます。
2. 登録後はプラモデルまたは塗料の該当一覧を表示します。
3. 写真の処理中は保存ボタンを無効にし、処理完了後に保存できます。
4. 編集画面では登録済み写真を確認し、1枚ずつ削除できます。
